# Profile specimen cover

`cover-wide.png` and `cover-mobile.png` are static renders of `cover.html`, the bundled Instrument Serif font and `pamnf6.svg`. Rebuild with Node 22+, Chrome and `render.mjs`; set `CDP_MODULE` to the local CDP helper. The separate PNGs make the cover self-contained when GitHub serves it as an image. The editable source and the font's [SIL Open Font License](InstrumentSerif-OFL.txt) are included. Instrument Serif is by The Instrument Serif Project Authors and licensed under OFL 1.1.

The specimen is a rendering of the **initial structure** for MaterialMind candidate `wbm-5-6788`. Eight recorded sites are repeated 2 × 2 × 2, yielding 64 sites. Colors, sphere radii and lighting are illustrative; no bonds are inferred. This is not a synthesis, measurement, newly generated DFT result, or physical-size model. [Fixed-revision figure data and worked case](https://github.com/nazeeh111/MaterialMind/blob/c879afa4b616649cac73ef46b010f24e12ed3544/docs/presentation/figure-data.json) and [case explanation](https://github.com/nazeeh111/MaterialMind/blob/c879afa4b616649cac73ef46b010f24e12ed3544/docs/presentation/README.md) are retained. The bundled `figure-data.json` is unchanged from that source.

The WBM initial structure comes from the Matbench Discovery collection by Janosh Riebesell and contributors, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Riebesell et al., [Matbench Discovery](https://doi.org/10.1038/s42256-025-01055-1); original WBM: Wang, Botti and Marques, [Predicting stable crystalline compounds using chemical similarity](https://doi.org/10.1038/s41524-020-00481-6). Dataset source: [figshare](https://doi.org/10.6084/m9.figshare.22715158). The [complete data and model attribution](DATA_LICENSE.md) is retained. The geometry is repeated and projected into an orthographic illustration; shading and palette are added. `geometry.cjs`, `materials.py`, `build.cjs`, and `interaction.src.js` preserve the specimen illustration generator inputs. Run `node build.cjs` from this directory to reproduce the illustration from the included data; it also emits an optional interactive script, which this static profile does not use. The rendered figure is static in this profile.

`cover.html` uses only the local font and specimen SVG, and `render.mjs` captures each plate without a network request. Rendering can vary with browser version. The picture's `alt` supplies the text identity to assistive technology.
