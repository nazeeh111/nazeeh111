# Profile geometry plate

`missing-body-light.svg` and `missing-body-dark.svg` are editable profile compositions of Solidrift's **original 132-triangle** input and recorded FLOAT output. They do not depict the later 12-triangle witness.

The mesh projections come from Solidrift's [`tests/fixtures/native-report.json`](https://github.com/nazeeh111/Solidrift/blob/8fc9e23471a18165d73646e290700cc10d351eea/tests/fixtures/native-report.json), generated by [`tools/tour/generate-geometry.py`](https://github.com/nazeeh111/Solidrift/blob/8fc9e23471a18165d73646e290700cc10d351eea/tools/tour/generate-geometry.py) at source commit `8fc9e23`. The profile composition keeps the input meshes and FLOAT output polygons; it omits the yellow MANIFOLD comparison wire from the output panel to show only what FLOAT returned. No solver result or mesh surface was generated for this image.

The original wide browser capture remains at `solidrift-evidence-v2.png` for comparison. The source projection SVGs and profile composition script are retained in this portfolio task's `work/profile-visual-prototype/` folder.
