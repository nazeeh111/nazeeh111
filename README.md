# Nazeeh Abdul-Hadi

### Make hidden behavior visible. Make the result runnable.

I build tools that let you keep native instructions, fork live execution, recover exact inputs, infer editable binary structure, design mechanical motion, and plan radio experiments. The interesting part is the mechanism. The finish line is a release someone else can actually run.

[Run compiled code on your images](https://nazeeh111.github.io/Capsulith/studio/image.html) · [Fork an execution](https://github.com/nazeeh111/Forkwake#try-it) · [Recover an inverse](https://github.com/nazeeh111/Rewynth/releases/tag/v0.2.0) · [Learn a file format](https://github.com/nazeeh111/Reclay/releases/tag/v0.1.0)

## Four ways to change what software can do

**[Capsulith](https://github.com/nazeeh111/Capsulith)** · Compiled code and initialized objects become portable APIs. Run an original ARM64 image codec on small PNG/QOI files, inspect returned pixel bytes and reopen native heap state in a fresh worker. The LZ4 demo carries dictionary history across workers. CPU emulation is supplied by the credited Unicorn.js engine. [Live image workbench](https://nazeeh111.github.io/Capsulith/studio/image.html) · [Object Studio](https://nazeeh111.github.io/Capsulith/) · [Release](https://github.com/nazeeh111/Capsulith/releases/tag/v0.3.0) · [Verified Linux/macOS delivery](https://github.com/nazeeh111/Capsulith/actions/runs/38477420431).

**[Forkwake](https://github.com/nazeeh111/Forkwake)** · One suspended workflow, multiple futures. Preserve live JavaScript/WebAssembly state at a named decision, change the answer, and inspect the outcome. Search a declared response tree for a failure requiring the fewest changed answers. Optional source-bound caller frames explain where a decision was made. [Run the example](https://github.com/nazeeh111/Forkwake#try-it).

**[Rewynth](https://github.com/nazeeh111/Rewynth)** · Turn supported register transformations backward. Build and check exact 32/64-bit inverses, inspect execution in both directions, and export runnable C. [64-bit release](https://github.com/nazeeh111/Rewynth/releases/tag/v0.2.0).

**[Reclay](https://github.com/nazeeh111/Reclay)** · Related files become an editable format model. Infer supported chunk rules, retain ambiguity, and compile standalone editors that update lengths, padding and CRC32. Real WAVE/AIFF edits match independent saves. [Release](https://github.com/nazeeh111/Reclay/releases/tag/v0.1.0).

These tools have explicit supported scopes. Their repositories include runnable examples, independent controls, failure behavior, licenses and verification limits. I prefer a precise capability to a universal claim.

## Motion and signals

**[Phaseglass](https://github.com/nazeeh111/Phaseglass)** · Fit here, predict there. Fit a coherent receiver sweep, then predict whole withheld positions with the locations and channel responses frozen. Keep reflected explanations and inspect a deliberate counterfeit that passes both checks while wrong. Original single-point simulation; coherence remains a trusted assumption. [Explore the recorded experiments](https://nazeeh111.github.io/Phaseglass/demo/) · [Run the full Studio](https://github.com/nazeeh111/Phaseglass#install-and-run).

**[Sweepforge](https://github.com/nazeeh111/Sweepforge)** · Draw timed motion, fit a one-motor linkage, and inspect what happens between animation frames. Checks modeled bar/tool clearances across a whole cycle and dimension tolerances; exports conceptual SVG/DXF patterns with source and independent replay. Includes a collision missed by 64 nominal frames. No hardware or physical-safety validation. [Browser demo](https://nazeeh111.github.io/Sweepforge/) · [Release](https://github.com/nazeeh111/Sweepforge/releases/tag/v0.1.0).

[SolidFrame CAD](https://nazeeh111.github.io/SolidFrame/) · [Camwright mechanisms](https://github.com/nazeeh111/Camwright) · [Muster scheduling](https://nazeeh111.github.io/Muster/) · [SchemaRehearsal migrations](https://github.com/nazeeh111/SchemaRehearsal) · [AgentLedger runs](https://nazeeh111.github.io/AgentLedger/)

Mechanical design, circuit analysis, graphics and sensing experiments are another part of the work. Live hardware and real-world accuracy are stated separately from simulation and recorded-data checks.

[Reclay](https://github.com/nazeeh111/Reclay) infers supported binary chunk rules from related files, retains competing interpretations and compiles standalone Python editors. Resize nested payloads with inferred length, padding and CRC32 updates. Real WAVE and AIFF edits match independent saves byte for byte; opaque content semantics remain explicit. [Download the release](https://github.com/nazeeh111/Reclay/releases/tag/v0.1.0).

**[Forkwake](https://github.com/nazeeh111/Forkwake)** splits a live JavaScript or WebAssembly workflow into independent futures at named decisions. It preserves suspended interpreter frames, closures, cyclic objects and Promise jobs, then searches a declared response tree for a failure with the fewest changed answers. Includes a local source editor, compiled SQLite transactions and portable deep cuts. [Run the JavaScript example](https://github.com/nazeeh111/Forkwake#try-it).

**[Rewynth](https://github.com/nazeeh111/Rewynth)** builds and checks inverses of supported 32/64-bit register transformations. Inspect forward and backward execution, recover inputs exactly, and export runnable inverse C code. [Download the 64-bit release](https://github.com/nazeeh111/Rewynth/releases/tag/v0.2.0).

**[Muster](https://github.com/nazeeh111/Muster)** repairs volunteer schedules while preserving locked commitments. It prioritizes coverage, then fewer changes, and explains staffing shortages; timed results state when optimality is unproven. [Open the worksheet](https://nazeeh111.github.io/Muster/).

**[Camwright](https://github.com/nazeeh111/Camwright)** designs in-line roller cams from an editable motion cycle. Geometry checks return Pass, Fail or Unresolved, with saved inputs and inspection evidence. [Run Camwright locally](https://github.com/nazeeh111/Camwright#run-locally).

**[Sley](https://github.com/nazeeh111/Sley)** adapts supported rising-shed weaving drafts to declared physical pedals and allowed pairs, preserving thread structure, colors and fixed tie-ups. It reports Feasible, Infeasible or Unknown and exports the draft and pedal instructions. [Run Sley locally](https://github.com/nazeeh111/Sley#run-locally).

**[Signelet](https://github.com/nazeeh111/Signelet)** transfers text annotations only when every minimum-cost character alignment agrees on an unchanged span under its alignment model. Ambiguous originals remain available for review. [Try the repeated-word example](https://github.com/nazeeh111/Signelet#try-the-example).

**[SchemaRehearsal](https://github.com/nazeeh111/SchemaRehearsal)** replays declared application scenarios on isolated before-and-after SQLite copies. Its example detects a lost payment-audit trigger despite preserved rows and passing integrity checks. [Rehearse the migration](https://github.com/nazeeh111/SchemaRehearsal#try-a-migration-that-loses-an-audit-trail).

**[AgentLedger](https://github.com/nazeeh111/AgentLedger)** runs bounded local task graphs, verifies artifacts and records command results. Durable checkpoints resume verified command tasks after interruption; Codex review is optional. [Run the offline example](https://github.com/nazeeh111/AgentLedger#run-the-complete-offline-example).

**[PhysicsBench](https://github.com/nazeeh111/PhysicsBench)** explores ideal projectile motion, mass–spring oscillation and one-dimensional collisions with time scrubbing, conservation checks and portable model sessions. Units and assumptions stay visible. [Open the physics lab](https://nazeeh111.github.io/PhysicsBench/).

## Graphics, sensing and developer tools

- **[SolidFrame](https://github.com/nazeeh111/SolidFrame)** · [Browser CAD](https://nazeeh111.github.io/SolidFrame/). Adds an editable mechanical part builder for drilled plates and brackets, hole-pattern validation, and a reorganized keyboard-accessible workspace, alongside the fixture and local-project safeguards.

- **[LumaField](https://github.com/nazeeh111/LumaField)** · [Browser viewer](https://nazeeh111.github.io/LumaField/). Adds local `.splat` and binary `.ply` loading, camera import, conversions, and an original procedural scene.

- **[PhotonRelay](https://github.com/nazeeh111/PhotonRelay)** · [Browser app](https://nazeeh111.github.io/PhotonRelay/). Adds a phone setup link and a channel lab for testing frame loss and duplication.

- **[EchoAtlas](https://github.com/nazeeh111/EchoAtlas)** · [macOS download](https://github.com/nazeeh111/EchoAtlas/releases/latest). Experimental acoustic gesture controls with calibration, stale-audio rejection, explicit stop controls, and analyzer replay. Live-hand accuracy still needs testing.

- **[MotionizedAudio](https://github.com/nazeeh111/MotionizedAudio)** · [Known-motion experiment](https://github.com/nazeeh111/MotionizedAudio/blob/main/experiments/known_motion.py). Adds a generated known-motion experiment, frequency and timing checks, and safer WAV output handling; real-speech recovery is unverified.

**[ToolScope](https://github.com/nazeeh111/ToolScope)** provides browser, CLI and terminal inspection plus offline comparison of exported tool definitions. [Try the offline example](https://github.com/nazeeh111/ToolScope#cli-and-terminal-interface).

**[WorkHarbor](https://github.com/nazeeh111/WorkHarbor)** provides a local task/run workspace with an isolated launcher and selected-file review packets. [Download the source](https://github.com/nazeeh111/WorkHarbor/releases/tag/v0.1.1). Board workflows, responsive draft retention, rejected-save recovery and mocked run lifecycles are tested; real provider execution remains unvalidated.

Source notes: SolidFrame uses Chili3D; LumaField uses antimatter15/splat; PhotonRelay uses Decimen Optical Transfer; ToolScope uses MCP Inspector; WorkHarbor uses Paperclip; MotionizedAudio continues the earlier VisualMic code. Each repository retains detailed credits and terms.
